# 🎯 Focus Games

Web app game rèn luyện sự tập trung, phong cách giao diện Minimal / Zen.
Viết bằng HTML, CSS, JavaScript thuần.

> 🚧 Đang phát triển.

## Giới thiệu

Bộ game nhỏ giúp luyện sự tập trung và khả năng kiềm chế phản xạ. Sau mỗi ván, app tính **điểm tập trung**, vẽ biểu đồ và lưu lịch sử chơi để người chơi thấy mình tiến bộ ra sao.

## Các game

- **Stroop Test (60 giây):** chọn màu của chữ, không phải nghĩa của chữ.
- **Anti-arrow:** bấm ngược hướng mũi tên, tốc độ tăng dần theo cấp.

## Tính năng

- Đo thời gian phản xạ
- Điểm tập trung và xếp loại
- Biểu đồ và trang lịch sử các lần chơi
- Chế độ sáng / tối

## Công nghệ

HTML, CSS, JavaScript, Chart.js, localStorage, Git/GitHub

## Cách chạy

Tải repo về, mở file `index.html` bằng trình duyệt. Không cần cài đặt.
